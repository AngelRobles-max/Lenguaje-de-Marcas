Ficha técnica: Python

Nombre: Python

Tipo: Lenguaje de programación de alto nivel, interpretado y de propósito general.

IDE significa entorno de desarrollo integrado. Python puede utilizarse desde distintos IDE, como Visual Studio Code o PyCharm.

Intérprete: programa que ejecuta instrucciones escritas en un lenguaje de programación, en este caso Python.

Ejemplo de código

El siguiente comando muestra un mensaje en pantalla:

print("¡Hola, mundo!")

Atajo de teclado

Para guardar un archivo en muchos editores se utiliza la combinación Ctrl + S.

Fecha relevante

La primera versión pública de Python se publicó el 20 de febrero de 1991.

Datos técnicos

Python tiene distintas versiones, como Python 3. Una potencia se puede escribir así: 23 = 8.
